Library Management System (Client - Server)

A client-server based library management system developed in Java.  
The system allows managing books, subscribers, and borrowing operations through a user friendly interface.

**Features**

  Subscriber Features
- Search for books
- Borrow and return books
- Extend borrowing period
- View borrowing history
- Update personal details
- View notifications and reminders

  Librarian Features
- Add and manage subscribers
- Borrow/return books for users
- View current borrowed books
- Generate reports
- Manage book inventory
- View notifications

  System Features
- Client-Server architecture
- Database integration for persistent data storage
- Multi user support
- GUI based interface with icons and screens
- Separation between client logic and server logic



**Architecture**

The system is built using a **Client-Server architecture**:

- Client - Handles UI and user interactions  
- Server - Processes requests and communicates with the database  
- Database - Stores books, users, and transactions  



**Technologies Used**

- Java
- JavaFX (GUI)
- Client-Server communication (Sockets)
- Database (MySQL)
